# Sportner Mobile

Application mobile Sportner (React Native + Expo + TypeScript + Expo Router).

## Structure

```
app/         écrans et navigation (Expo Router)
components/  composants UI réutilisables
lib/         logique/utilitaires partagés
types/       types TypeScript partagés
constants/   constantes (thème, config, ...)
assets/      images et icônes
```

## Démarrer

```bash
npm install
npm start
```

Scanne le QR code affiché avec l'app **Expo Go** (iOS/Android) pour ouvrir l'app sur ton téléphone.
